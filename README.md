# Bankist

A minimalist landing page for a fictional digital bank, built with vanilla HTML, CSS and JavaScript (no frameworks, no build step).

**Live demo:** _add your link here_

## Features

- Sticky navigation (Intersection Observer) and smooth scrolling
- Tabbed "Operations" component
- Testimonial slider with dots and keyboard arrows
- Modal window with a demo sign-up form
- Section reveal on scroll and lazy-loaded images
- Fully responsive (desktop, tablet, phone)

## Run locally

Open `index.html` in a browser. No install needed.
